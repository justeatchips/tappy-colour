# Kid-Test Observation Template

Use this at the end of a milestone or before expanding scope. The aim is to learn whether a child can start, keep going, finish, and feel proud without adult instruction.

- Date:
- Child age:

- Starting state: fresh install / saved gallery / offline / other
- Source used: starter / photo import / camera / search

## Prompt

Say only:

> Have a go.

Avoid explaining the interface for the first five minutes unless the child is upset or truly stuck.

## Observe First Five Minutes

### Start

- What did they tap first?
- Did they understand Camera / Photos / starter pictures?
- Did they hesitate before choosing a source?
- Did any adult have to intervene?

### Conversion Preview

- Did they understand how to start?
- Did they adjust difficulty?
- Did they notice or use preview/crop controls?
- Which controls were ignored?
- Which labels or icons caused questions?

### Painting

- Did they understand selected colour/number?
- Did they paint a correct cell without help?
- Did they discover drag, bucket, fill-all, undo, or hint?
- What wrong taps happened?
- Did feedback help or frustrate?

### Emotion

- Where did they smile, laugh, or show pride?
- Where did they sigh, stop, or look away?
- Did the picture still feel like "mine" after conversion?
