Animation: the "bob"

Active mascots bob — selected on onboarding, on the difficulty/completion screens, when celebrating. Idle mascots stay still.

animated
1.4s · steps(2) · infinite
idle
no transform

Why steps(2)? It keeps the animation feeling like 2-frame pixel-art animation — punchy, not floaty. A linear ease betrays the pixel aesthetic.

Implementation

Web

Use the SVGs — small (1–4 KB each), infinite scale, no image-rendering needed.

// global.css
.mascot-bob {
  transform-origin: 50% 90%;
  animation: mascot-bob 1.4s steps(2) infinite;
}
@keyframes mascot-bob {
  0%,100% { transform: translateY(0) rotate(-2deg); }
  50%      { transform: translateY(-1px) rotate(2deg); }
}
// React
<img
  src={`/mascots/svg/${id}.svg`}
  width={size} height={size}
  className={active ? 'mascot-bob' : ''}
  alt={name}
/>

iOS — SwiftUI

Drag the PNGs into Assets.xcassets. Use .interpolation(.none) — without it iOS smooths the upscale and the pixels go fuzzy.

struct MascotView: View {
    let id: String
    let size: CGFloat
    @State private var bobUp = false

    var body: some View {
        Image(id)
            .interpolation(.none)
            .resizable()
            .frame(width: size, height: size)
            .rotationEffect(
                .degrees(bobUp ? 2 : -2),
                anchor: .bottom)
            .offset(y: bobUp ? -1 : 0)
            .animation(
                .linear(duration: 0.7)
                    .repeatForever(autoreverses: true),
                value: bobUp)
            .onAppear { bobUp = true }
    }
}

Platform checklist

Web

  • ☐ Copy svg/ + png/ into public/mascots/
  • ☐ Add .mascot-bob keyframes to global CSS
  • ☐ Render SVG via <img> (no flag) or PNG with image-rendering: pixelated
  • ☐ Don't wrap in elements with CSS filter or non-integer transform: scale() — that introduces subpixel rendering
  • ☐ Mascots animate only when active; idle list states stay still

iOS

  • ☐ Drop PNGs into Mascots.xcassets, one image-set per mascot
  • ☐ Verify .interpolation(.none) (SwiftUI) or .nearest magnification filter (UIKit)
  • ☐ Sizes: integer multiples of 32pt (32, 64, 96, 128, 192, 256)
  • ☐ Don't substitute spring animations — keep linear + repeat-autoreverse
  • ☐ Bob anchor = .bottom, not .center
